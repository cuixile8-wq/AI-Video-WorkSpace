# 3D动漫游戏电影感适配预设

## 适用范围

适用于3D动漫、游戏二创、虚拟角色短剧和需要电影摄影语言但不能真人化的项目。

## 标准前缀

```text
[3D ANIME GAME CINEMATIC STYLE LOCK]

3D动漫游戏二创风格，严格保持角色参考图中的脸型、发型、服装、体型、武器和材质，不转化为写实真人。虚拟摄影机参考 ARRI Alexa 65 的高动态范围与大画幅空间感，使用 Cooke vintage cinema lens 风格：主体中心轮廓与装备细节清楚，边缘过渡柔和，焦外自然，不做数码过度锐化。

色彩参考 Kodak Vision3 500T 的柔和高光、完整暗部和中等饱和度，但保留游戏场景原有色板。日光场景进行自然校色，禁止整体偏蓝、偏黄或偏绿。胶片颗粒保持非常轻微，只作为画面统一层，不能覆盖动漫角色面部、装备纹理和游戏界面细节。

使用符合场景来源的自然环境光、窗户光、灯带光与材质反射光。人物微表情、呼吸、手部动作与身体重心自然，避免僵硬摆拍和夸张颜艺。动态动作保留适量运动模糊，但武器、脸部和关键动作节点必须可读。

景深按镜头功能调整：场景建立镜头保留较深景深；三人关系镜头保证所有关键人物清楚；角色近景可使用柔和浅景深；战斗镜头不能因过度虚化丢失空间、敌我位置和技能装置。

保留3D角色皮肤材质、织物、皮革、金属、建筑与武器表面的细节，不添加真人毛孔、真人皱纹或写实皮肤瑕疵，不产生塑料感、蜡像感和HDR锐化白边。
```

## 推荐负面约束

```text
禁止真人化、换脸、换装、发型漂移、角色复制、额外人物、完整镜面倒影、塑料材质、蜡像皮肤、过度景深虚化、过量胶片颗粒、数字噪点、压缩色块、HDR过锐、霓虹光污染、技能光效淹没人物、陌生场景、文字、水印和平台标识。
```

## 三角洲项目调用补充

- 总裁办公室和走廊优先服从游戏场景参考图，摄影预设不能改变空间结构。
- 多人镜头优先保证站位和武器动作清楚，不追求极浅景深。
- 玻璃只表现环境灯带和模糊光影，禁止出现完整角色倒影。
- 战斗镜头的运动模糊只出现在肢体或摄影机运动轨迹上，脸部、枪口方向、技能装置和命中结果必须清楚。
- 胶片颗粒应低于真人写实项目，避免破坏3D动漫画面的干净度。
- 角色皮肤保留动漫化材质细节，不调用真人毛孔与皱纹规则。
