# Seedance 2.5适配规范

本规范是现有分镜提示词知识库的附加调用层，不替代原有13字段、风格预设和摄影冲突消解规则。

适用于Seedance 2.5及接入该模型的平台。不同平台开放的参考素材数量、分辨率、最长时长、续写和编辑功能可能不同，实际使用时以平台界面为准。

## 一、调用位置

原有13字段保持不变：

```text
景别
关系位
运镜
焦点
主体与动作
画面内容
场景环境
光影色调
构图
视觉风格/画质
音效/微动态
人物台词配音
约束
```

调用Seedance 2.5时，只增加三个模块：

1. 在13字段之前增加“输入资产映射”。
2. 在“主体与动作”字段内部增加“长镜头时间轴”。
3. 在“约束”字段之后增加“结束状态”。

推荐顺序：

```text
[输出规格]
[输入资产映射]
[项目风格与角色场景锁定]
原有13字段
[结束状态]
```

## 二、输入资产映射

### 1. 基本原则

每个参考素材必须明确“参考什么”和“不参考什么”。禁止只堆放素材名称而不分配职责。

正确写法：

```text
@[角色参考图]：只锁定脸型、发型、服装、体型、装备和材质，不参考背景、构图和动作。
@[场景参考图]：只锁定空间结构、门窗方向、材质、色板和灯光来源，不生成图中人物。
@[动作参考视频]：只参考身体动作、重心、节奏和接触关系，不复制人物身份、服装、背景和镜头画幅。
@[运镜参考视频]：只参考摄影机高度、方向、速度和运动轨迹，不复制人物动作、场景和色彩。
@[声音参考]：只参考节奏、音色或环境声层次，不生成参考素材中未指定的画面人物和事件。
```

错误写法：

```text
参考这些图片和视频生成同样效果。
```

这种写法没有划分职责，容易造成换脸、换装、背景串入、动作照搬和构图冲突。

### 2. 输入类型与责任

#### 角色参考图

负责：

- 人物身份、脸型、发型、年龄感和体型。
- 服装、鞋靴、武器、护具、首饰和固定伤痕。
- 真人或3D动漫的材质类型。

不负责：

- 当前镜头动作。
- 当前镜头站位。
- 场景结构和运镜。

多人镜头必须分别标注每张角色图对应谁，不能让模型自行判断。

#### 场景参考图

负责：

- 空间结构、入口方向、玻璃位置、家具或掩体位置。
- 建筑材质、主色板、光源方向和时代地域特征。
- 镜头之间需要保持的固定物件。

不负责：

- 参考图中的临时人物、文字和水印。
- 当前镜头的人物数量与动作。

场景结构与文字描述冲突时，按原知识库优先级执行：项目明确要求高于参考图中的偶然错误；其余情况优先保持场景锚定。

#### 动作参考视频

负责：

- 身体动作顺序、速度、重心变化和发力方式。
- 人与人、人与物的接触时机。
- 蹲、走、跑、翻身、拔枪、开门等动作轨迹。

不负责：

- 参考视频人物的脸、服装和身体特征。
- 参考视频背景、色彩、光线和镜头画幅。
- 未被文字明确保留的打斗结果。

动作参考必须注明是否允许创意改编：

```text
严格复现动作节奏，但人物、服装和场景全部以本项目参考图为准。
```

或：

```text
只提取低重心潜行动作逻辑，步法与微动作允许根据当前走廊空间重新设计。
```

#### 运镜参考视频

负责：

- 摄影机高度、轴线、移动方向、速度和停点。
- 推、拉、摇、移、跟、环绕或手持呼吸感。
- 遮挡揭示和焦点转移节奏。

不负责：

- 人物表演和动作结果。
- 参考场景与当前场景的物件替换。

一个时间段只保留一个主要运镜意图。若动作参考和运镜参考同时存在，必须分别说明职责。

#### 首帧与尾帧

首帧负责当前镜头的起始站位、服装、空间和摄影机位置。尾帧负责目标构图，不应同时要求与尾帧相反的动作结果。

若平台支持首尾帧控制，应明确：

```text
首帧：严格锁定人物起始位置和摄影机轴线。
尾帧：只锁定结束构图与人物最终站位，中间动作按时间轴自然完成。
```

#### 音频参考

负责：

- 台词节奏、环境声层次、动作音效时点或情绪变化。
- 已明确指定的声音来源。

不负责：

- 根据声音自行增加画外人物。
- 自动生成背景音乐。
- 把制作备注或中文翻译朗读出来。

同一成片只放入一种目标配音语言。英中对照剧本中的中文翻译属于制作备注，不能与英文台词一起复制到生成台词区。

### 3. 输入资产映射模板

```text
[INPUT MAP]

@[角色A参考图]：锁定角色A的脸型、发型、服装、体型和装备；不参考背景与动作。
@[角色B参考图]：锁定角色B的脸型、发型、服装、体型和装备；不参考背景与动作。
@[场景参考图]：锁定空间结构、材质、色板和光源方向；忽略图中临时人物与文字。
@[动作参考视频]：只参考动作顺序、重心和节奏；不复制人物、服装、背景和运镜。
@[运镜参考视频]：只参考摄影机高度、运动方向、速度和停点；不复制人物动作与场景。
@[声音参考]：只参考环境声或动作音效节奏；不生成BGM和额外人物。
```

未使用的输入类型直接删除，不要保留空项。

### 4. 输入冲突优先级

输入资产之间冲突时，按以下顺序处理：

1. 当前镜头的明确人数、剧情结果和安全约束。
2. 角色身份参考图。
3. 场景结构参考图。
4. 当前镜头动作时间轴。
5. 动作参考视频。
6. 运镜参考视频。
7. 色卡与摄影风格。
8. 音频节奏和画质修饰。

若动作参考视频与文字时间轴冲突，以文字时间轴为准；若运镜参考导致越轴、拍到禁区或破坏场景结构，应舍弃参考运镜中的冲突部分。

## 三、长镜头时间轴

### 1. 时长选择

Seedance 2.5支持更长生成，不代表所有镜头都应使用最长时长。

- 5至8秒：单一精确动作、道具特写、足部镜头、反应镜头。
- 8至15秒：标准人物表演、简单对话、两至三个连续动作。
- 15至20秒：同一场景内的完整调度、多人关系变化、连续对话。
- 20至30秒：空间稳定、人物数量有限、因果关系清楚的长镜头。

战斗命中、多人交叉移动、镜面场景、足部精确队列和容易复制人物的镜头，仍优先使用较短时长。

### 2. 长镜头拆分原则

每个时间段只安排一个主要叙事动作，并回答四件事：

1. 谁行动。
2. 从哪里到哪里。
3. 摄影机如何承接。
4. 动作结束后留下什么状态。

动作必须具有因果顺序：

```text
观察异常 → 停步 → 检查痕迹 → 得出判断 → 下达指令 → 队友起步。
```

不能写成相互冲突的并列命令：

```text
角色保持完全静止，同时快速跑向门口并回头观察。
```

### 3. 推荐时间轴结构

#### 8秒精确镜头

```text
0s-2s：建立起始构图和动作准备。
2s-5.5s：完成唯一核心动作。
5.5s-8s：动作收束，稳定停留，为下一镜留下衔接状态。
```

#### 15秒标准镜头

```text
0s-3s：建立人物、空间和初始状态。
3s-7s：动作A发生并产生结果。
7s-11s：角色根据结果做出反应或完成动作B。
11s-15s：镜头收束，固定结束站位和视线。
```

#### 20秒长镜头

```text
0s-3s：场景与人物关系建立。
3s-7s：动作A，摄影机只执行第一段主要运动。
7s-12s：动作A结果触发动作B，人物关系发生变化。
12s-16s：对白、反应或道具交互。
16s-19s：人物进入最终站位，摄影机减速。
19s-20s：保持结束画面至少1秒，不增加新动作。
```

#### 30秒长镜头

```text
0s-4s：建立场景、人物数量、站位和镜头轴线。
4s-9s：第一动作单元。
9s-15s：第二动作单元，由第一动作结果自然触发。
15s-21s：第三动作单元或核心对白。
21s-26s：人物反应、位置调整和情绪变化。
26s-29s：摄影机与动作共同减速，进入结束状态。
29s-30s：稳定保持，不再加入新人物、新道具或新剧情。
```

### 4. 运镜规则

- 单镜头连续完成时，明确写“单镜头、无剪切”。
- 一个时间段只能有一种主要摄影机动作。
- 运镜改变必须由人物动作、遮挡或视线触发。
- 禁止在同一时刻同时要求固定机位、快速环绕、推近、拉远和升降。
- 长镜头最后1至2秒应减速并稳定，避免尾帧漂移。
- 若需要多镜头叙事，使用独立镜头块或明确的 `HARD CUT`，不要把剪辑命令伪装成一次连续运镜。

### 5. 多人调度规则

- 首段先声明总人数和每个人的初始位置。
- 每段只让一至两名角色承担主要动作，其余角色使用呼吸、视线、握把、重心等微动作维持存在。
- 明确谁先、谁后、谁停留，避免“所有人同时做不同复杂动作”。
- 多人交叉时写清前后层、左右侧和是否允许越轴。
- 每次位置变化后，在下一时间段重新确认关系位。
- 相似角色必须用A/B、服装识别色、武器或固定左右位置区分。

### 6. 对白与声音时间轴

对白应写明说话人、开始与结束时间、语言和是否画外音：

```text
3.2s-5.6s EN 角色A：`Keep the door closed.`
6.1s-8.0s EN 角色B：`Understood.`
```

要求无原生对白时：

```text
画面生成阶段不生成对白、旁白或口型，台词后期配音。
```

要求只生成环境与动作音时：

```text
只生成环境音、动作音和物体音效；无BGM、无旁白、无自动歌词、无随机人声。
```

声音先行或延续必须写明来源，不能因脚步声自动生成画外人物。

### 7. 主体与动作字段写法

长镜头时间轴直接写在原有“主体与动作”字段内：

```text
主体与动作：
0s-3s：角色A位于门左侧，抬手示意停止；角色B和角色C依次停步。
3s-8s：角色A半蹲检查地面痕迹，角色B保持左侧警戒，角色C观察右侧入口。
8s-12s：角色A起身下令，角色B先压低重心，角色C晚半拍迈出第一步。
12s-15s：三人进入最终推进队形，保持半秒稳定，不开始下一项动作。
```

不要在“运镜”“画面内容”和“主体与动作”中分别写三套互相不同的时间线。

## 四、结束状态规范

### 1. 作用

结束状态不是重复最后一个动作，而是为续写、下一镜和局部编辑提供明确锚点。

每镜结束时至少锁定：

- 人物最终位置。
- 身体姿态和朝向。
- 视线方向。
- 手部、武器与关键道具状态。
- 摄影机景别、高度、方向和轴线。
- 门、箱体、灯光、破坏痕迹等场景状态。
- 最后一段声音是否继续进入下一镜。

### 2. 人物结束状态

正确写法：

```text
角色A停在门框左侧半蹲，枪口朝向走廊；角色B位于右侧箱体后，左手扶住箱盖；角色C站在后方中线。三人视线都指向办公室门，不重新起步。
```

避免：

```text
三人准备继续行动。
```

后者没有位置、姿态和方向，下一镜容易重置。

### 3. 道具与场景结束状态

必须说明会影响下一镜的状态：

- 关键道具由谁持有，左手还是右手，位于人物身体哪一侧。
- 门是打开、半开还是锁住。
- 箱盖是打开、关闭还是被手压住。
- 电视机、台灯、电脑、手机屏幕、车灯、火源等固定光源是否开启，是否继续发光或闪烁。
- 电视机、收音机、机器、报警器、流水、雨声等固定声音源是否继续发声，是否延续到下一镜。
- 武器是否上膛、枪口朝向哪里。
- 关键物品在谁手中或掉在何处。
- 人物留下的脚印、弹壳、血迹或破坏是否继续存在。
- 灯光、烟雾、雨水和机械装置是否仍在运动。

禁止下一镜无理由恢复原状。

道具持手硬约束：

```text
凡是手机、文件、钥匙、武器、项链、戒指、饼干、试管、报告、箱包等关键道具，必须写清持有人、左手/右手、身体侧、朝向、状态和结束落点。
如果发生递交、换手、掉落、放下、收入袋中或被他人夺走，必须在时间轴中可见。
同一只手不能同时执行互相冲突的动作，例如右手拿手机同时又右手开窗、撑床、擦泪、指向或抓人；需要切换时必须说明另一只手接管。
```

固定场景道具状态硬约束：

```text
凡是电视机、门窗、台灯、电脑、保险箱、车辆、屏幕、火源、机器等固定场景道具，必须写清世界坐标位置、开关/开合/运行状态、是否作为光源或声音源、下一镜是否继承。
如果电视机开启、台灯亮着、门半开、保险箱打开、车辆停在门口，后续镜头默认继续保持该状态，除非时间轴明确展示关闭、移动、熄灭、合上或离开。
固定道具全片统一用简单名称，例如“电视机、沙发、床、饼干、手机”。不要反复添加“老旧、红色、破旧”等形容词，也不要在不同镜头里频繁换叫法，避免模型误判为新增同类物品。
禁止固定道具无过程消失、换边、恢复原状、变成其他物品、停止发光或停止发声。
```

NeoWOW 默认执行提醒：

```text
用户默认生成软件为 NeoWOW。提示词要使用简单稳定的物品名称、清楚的动作链和明确结束状态；当一个镜头反复生成错误时，不只改小词，应重写动作结构、构图关系或镜头路径，让 NeoWOW 能识别为新的生成意图。
```

总控约束单段输出硬约束：

```text
场景连续、人物关系、打光锁定、道具连续性和固定场景道具状态等总控内容，默认写成“字段名 + 单段一句话”，直接可复制到全局统一约束或逐镜提示词中；不要拆成长篇说明、教学解释或多级清单。
打光锁定：所有镜头光源必须来自场景中真实存在的窗户、台灯、电视或手机等固定位置，明确主光从哪里来、照到人物哪一侧、另一侧保留多少自然暗部，并通过墙面、地面和家具产生弱反射补光；背景高光不得过曝，黑发、深色衣物、玻璃、床单、木材和动物毛发必须保留真实纹理与明暗层次；摄影机换机位、反打或人物移动时，光源位置和方向不得跟随镜头翻转，只允许人物受光比例自然变化，整场曝光和色温保持连续。
```

### 4. 摄影机结束状态

写清：

```text
摄影机最终停在人物腰部高度的三人中景，朝办公室方向，保持原轴线，不越过走廊中线。
```

若下一镜要从足部、道具或反打开始，应说明可使用的匹配切点：

```text
最后停在角色右脚落地，下一镜可从同一只脚的落地特写继续。
```

### 5. 声音结束状态

声音可用于连接镜头：

```text
最后一次门锁声延续0.3秒进入下一镜。
```

或明确停止：

```text
搜索声在脚步出现后完全停止，只保留环境低频声。
```

### 6. 悬念断点

动作未完成的结尾必须锁定“不展示什么”：

```text
男主手掌悬在半空，距离对方脸部约30厘米；动作尚未落下即硬切黑场。不得生成接触、撞击声、伤痕或对方被打后的反应。
```

这类约束可避免模型替创作者自动补完结果。

### 7. 结束状态模板

```text
[END STATE]

人物：
角色A最终位于______，保持______姿态，面向______；角色B最终位于______。

手部/道具：
角色A右手______；角色A左手______；关键道具位于______；门/箱体/武器处于______状态。

摄影机：
最终景别______，机位高度______，朝向______，保持______轴线。

场景：
```

## 六、项目使用建议

### 真人短剧

- 继续调用电影级写实摄影预设。
- 亲密、掌掴、武器伤害和身份骗局必须在结束状态中锁定尺度与结果。
- 英语版、西语版分别生成或后期配音，不能把两种台词和中文翻译同时放入原生配音区。

### 3D动漫游戏二创

- 继续调用3D动漫游戏电影感预设。
- 角色参考图优先级高于动作参考视频中的人物外形。
- 多人战斗、镜面、玻璃和技能装置仍要保留人数、倒影和关键道具限制。
- 3D动漫去AI感默认执行“关系、因果、不完美”：主角动作先触发配角或环境反应，配角动作错峰发生；镜头允许绳索、布料、门框、阴影、树叶、烟尘短暂遮挡主体，焦点可以慢半拍找回主体，但不得影响关键剧情信息。
- 真实感检查默认加入光影、空气和身体反馈：光穿过树叶、窗帘、烟雾、尘埃或雾气后要影响人物脸部、衣服、地面和墙面；人物跑动、打斗、疲惫、惊吓或施法后必须有汗水、喘息、发丝/衣物扰动、重心调整和情绪表情，禁止长时间运动后仍干净完美。
- 精确足部、枪口、命中和装置落地镜头优先使用5至10秒，不因模型支持30秒而盲目延长。
- NeoWOW生成时，固定家具、电视机、门窗、玻璃、沙发、茶几等不要在每个镜头里反复作为“前景/中景/后景主体”出现；景层优先写行动主体和空间关系，固定物体只写边缘入画、透明隔层、反光、光声影响或状态继承；涉及窗户或玻璃时必须写清角色在室内侧还是室外侧，玻璃只作为透明隔层，不作为可移动前景物体。

### 长镜头生成失败时

出现以下任一情况，应拆成两个镜头，而不是继续增加约束：

- 人物身份或服装在中段漂移。
- 三人以上频繁交叉换位。
- 镜头同时发生复杂运镜和复杂肢体接触。
- 道具在不同时间段反复消失或换手。
- 对白、动作和声音无法在同一时间轴内清楚对应。
- 结尾状态无法稳定保持至少1秒。
