# 分镜提示词知识库

本知识库用于生成和检查电影、真人短剧、3D动漫游戏二创的分镜提示词。风格预设属于可选模块，不是所有项目的默认前缀。

## 使用顺序

1. 判断项目类型：写实真人、历史写实、3D动漫游戏二创或其他风格。
2. 从“风格预设”中选择一个主预设。
3. 根据景别调整景深、颗粒、运动模糊和锐度。
4. 添加项目专属的场景锁定、角色锁定、色卡和人数限制。
5. 使用“规则”中的冲突消解条目进行最终检查。

## 风格预设

- [电影级写实摄影预设](风格预设/电影级写实摄影预设.md)：真人短剧、历史写实、纪实感场景。
- [3D动漫游戏电影感适配预设](风格预设/3D动漫游戏电影感适配预设.md)：游戏二创、3D动漫角色、虚拟摄影机镜头。

## 规则

- [摄影与画质冲突消解规则](规则/摄影与画质冲突消解规则.md)：解决胶片颗粒与降噪、复古柔化与清晰度、景深和运动模糊等冲突。
- [Seedance 2.5适配规范](规则/Seedance%202.5适配规范.md)：在保留原13字段的前提下，增加输入资产映射、长镜头时间轴和结束状态规范。

## 调用原则

- 风格预设只负责摄影、色彩、光线和材质，不替代剧情、动作时间轴与镜头衔接。
- 参考图负责角色和场景身份，文字预设负责视觉语言，两者不要混为一项。
- 每个镜头只重复最容易出错的限制，避免长篇重复稀释动作指令。
- 项目类型明确后不做折中：真人短剧默认按真人现场摄影、克制表演和真实光影设计；3D漫默认按虚拟摄影机、空间视差、速度变化和大胆镜头张力设计，除非用户明确要求混合。
- 使用Seedance 2.5时，先调用适配规范，再调用项目风格预设和原13字段；适配规范不改变原有冲突优先级。
- 生成或检查全片时优先排查“只看、只愣、只确认、只反应”的空转镜头；角色看到信息后要尽快转化为可见动作，结束状态必须成为下一镜的动作入口。
- 每个镜头都要有故事感：角色此刻想做什么、遇到什么阻碍、结束后局面改变了什么；反应镜头如果不改变信息、关系或危险程度，应合并或改写。
- 去AI感默认执行“关系、因果、不完美”：主体必须和环境、配角、道具发生可见关系，动作必须有先后触发和重量反馈，配角与环境动作不得同时启动，摄影机允许被前景遮挡、慢半拍找焦点或被阴影压住主体一部分。
- 关键道具必须锁定持有人、左手/右手、身体侧、状态、落点和下一镜继承；换手、递交、掉落、放下必须写进时间轴，不能让模型自动恢复或换手。
- 固定场景道具必须锁定位置、开关/开合/运行、发光和发声状态；例如电视机一旦开启，后续镜头默认继续开启并提供冷蓝光和底噪，除非时间轴明确关闭。
- 固定道具全片统一用简单名称：电视机、沙发、床、饼干、手机等；不要反复加“老旧、红色、破旧”等形容词，也不要频繁换叫法，避免模型生成多个同类物品。
- 固定家具、门窗、玻璃、电视机等不要在每个镜头里反复作为前景/中景/后景主体；单镜只写可见程度、透明隔层、反光、光声影响和室内外位置，防止模型把固定物体生成多个或让角色穿越空间。
- 用户默认视频生成软件为 NeoWOW；提示词优先按 NeoWOW 的识别习惯书写，物品命名要简单稳定，重要变化要大幅改写，不依赖轻微小改触发模型理解。
- 写实预设中的皮肤毛孔、皱纹和生活化瑕疵不能直接套用到3D动漫角色。
- 最终画幅必须按项目单独指定，例如16:9、9:16或2.39:1。
